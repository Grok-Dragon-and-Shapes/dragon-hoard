# dragon-hoard

Трекер сокровищ дракона: самородки, руды и добыча по биомам с итогами в логове.

## Запуск

Открой `index.html` в браузере. Данные хранятся в localStorage этого браузера.

## Что есть

- Добавление находок по биому и предмету, повторные добавления складываются.
- Итоги по всему логову и по категориям: самородки, руды, добыча.
- Список по каждому биому с возможностью убрать строку.
- Очистка всего логова.

## Где менять списки

Биомы, категории и предметы лежат в начале `app.js` (`BIOMES`, `CATEGORIES`, `ITEMS`).
